# MORAI AROMA

Одностраничный сайт селективной парфюмерии: тёмная «лесная» палитра, золотые акценты, крупная антиква в заголовках.

Статический сайт без сборки и зависимостей: чистый HTML, CSS и JavaScript. Открывается двойным щелчком по `index.html` либо через GitHub Pages.

## Структура

```
.
├── index.html              разметка всех секций
├── css/
│   ├── style.css           основная тема и адаптив
│   └── fonts.css           @font-face для локальных шрифтов
├── js/
│   └── main.js             слайдер, меню, избранное, корзина, отзывы, подписка
└── assets/
    ├── fonts/              Playfair Display и Inter (woff2, кириллица + латиница)
    └── img/                вся графика в SVG
```

## Как заменить графику на реальные фотографии

Баннер использует готовый рендер 1600×900 (`assets/img/hero-photo.jpg`). Чтобы поставить другую фотографию, положите её под тем же именем — правки вёрстки не нужны. Если снимок будет уже по пропорциям, поправьте `background-position` у `.hero__bg--photo` в `css/style.css`.

Важно: не оборачивайте растровую картинку в SVG. Файл со встроенным base64-JPEG раздувается примерно на четверть и ломается при просмотре и правке на GitHub — там SVG очищается от встроенных `data:`-изображений. Если картинка пришла в таком виде, её достаточно распаковать в обычный JPEG: качество не меняется, а файл становится легче.

Все изображения сайта — обычные JPEG в `assets/img/`, поэтому замена не требует правок вёрстки: положите файл под тем же именем и сохраните пропорции. Вектором остаётся только `favicon.svg`.

| Файл | Где используется | Размер |
| --- | --- | --- |
| `hero-photo.jpg` | фотография баннера (филин и флакон) | 1600×900 |
| `hero-photo-blur.jpg` | размытая подложка баннера на компьютере | 1600×900 |
| `hero-og.jpg` | превью ссылки в соцсетях | 1200×630 |
| `col-her.jpg`, `col-him.jpg`, `col-unisex.jpg`, `col-gift.jpg` | карточки коллекций и 2-й слайд баннера | 800×1000 |
| `owl-eye.jpg` | 3-й слайд баннера и секция «О бренде» | 1600×700 |
| `prod-1.jpg` … `prod-5.jpg` | карточки товаров | 800×640 |
| `avatar.jpg` | аватары в отзывах | 200×200 |
| `favicon.svg` | иконка вкладки | 64×64 |

Порядок замены: положите фотографию рядом (например `hero.jpg`), поправьте расширение в `index.html` или `style.css`. Фотографии лучше брать в тёмной тональности — тема рассчитана на глубокие тени и тёплый свет.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`, корень репозитория. Файл `.nojekyll` отключает обработку Jekyll, чтобы отдавались все файлы как есть.

## Что реализовано в JavaScript

- слайдер баннера: автопрокрутка 7 секунд, стрелки, клавиши ← →, свайп, пауза при наведении и в фоновой вкладке;
- счётчик и прогресс-линия активного слайда;
- мобильное меню-панель с закрытием по Esc, по клику вне и по выбору пункта;
- фон шапки при прокрутке;
- избранное: переключатель и счётчик (у первых двух товаров предустановлено);
- корзина: счётчик и всплывающие уведомления;
- прокрутка отзывов с возвратом в начало;
- валидация формы подписки с состоянием ошибки;
- появление секций при прокрутке через `IntersectionObserver`;
- уважение к `prefers-reduced-motion`: анимации и автопрокрутка отключаются.

## Ограничения демо-версии

Корзина, избранное и подписка работают только на стороне клиента: данные не сохраняются и никуда не отправляются. Для реального магазина потребуется бэкенд, отправка формы и сохранение состояния.
